# X 时间线翻译（Tampermonkey）

用于 X / Twitter 首页 **For You / Following** 时间线的用户脚本。点击推文下方的按钮，将正文发送到自己配置的后端，保留原文并展示译文。

**当前状态：前端已实现，尚未发布；同仓库的 `x-translator-server` 还没有翻译接口，因此仅安装脚本不能获得真实译文。** 必须先提供符合下述约定的后端。本项目不内置翻译供应商，也不模拟真实翻译结果。

## 安装与使用

1. 在桌面浏览器中安装 Tampermonkey，并按其提示启用用户脚本运行权限。
2. 新建用户脚本，将 `x-timeline-translator.user.js` 的完整内容粘贴进去，替换默认代码并保存。无需 npm 或打包。
3. 打开或刷新 `https://x.com/home`（也支持 `https://twitter.com/home`）。
4. 点击左下角“翻译设置”，或 Tampermonkey 菜单中的“设置翻译接口和目标语言”。
5. 填入**完整翻译接口地址**，例如 `https://你的服务.workers.dev/api/translate`，选择目标语言并保存。此处不要填写供应商 API 密钥。
6. 点击推文下方“翻译”。如果 Tampermonkey 询问连接权限，仅允许你自己的可信后端域名。

默认目标语言为简体中文。接口地址及目标语言保存在 Tampermonkey 存储中，刷新后仍然有效。翻译失败时显示原因，可以点击“重试翻译”。译文支持收起和展开。

## 已实现的行为

- 只在首页时间线添加按钮，不在个人主页、搜索页或单条推文页添加按钮。
- 监听动态插入、正文修改及节点替换，适配滚动加载和时间线切换；不自动点击推文或自动发起翻译。
- 提取正文中的文字、换行和表情图片的替代文本，不读取图片内容或视频字幕。
- 不单独翻译引用卡片；仅包含引用卡片而没有外层正文的推文不添加按钮。
- 译文按纯文本展示，不执行后端返回的 HTML 或代码。
- 同一接口、原文、目标语言的请求合并；当前页面缓存最多 200 条译文。刷新页面或保存设置会清空缓存，缓存不持久化。
- 最多同时发送 4 个不同的翻译请求；单条正文限制 20,000 个 JavaScript 字符单位，请求超时 30 秒。失败不会自动重试。
- 切换设置、替换推文正文或移除节点后，旧请求不会覆盖当前译文。已发出的请求不会撤回，仍可能产生后端费用。

默认面向桌面 Chromium / Firefox + Tampermonkey。DOM 行为已有模拟环境测试，**尚未在登录后的真实 X 页面及各浏览器中人工验收**。X 的 `data-testid` 和引用卡片结构变化后可能需要适配。

## 后端接口约定

脚本使用 `GM_xmlhttpRequest` 发起跨域请求，不使用 X 页面的 Cookie。配置地址必须是 HTTPS；本地开发允许 `http://localhost:8787/api/translate`、`127.0.0.1` 和 IPv6 回环地址。禁止地址包含用户名、密码、查询参数或 URL 片段。

请求：`POST <配置的完整地址>`，`Content-Type: application/json`。

```json
{
  "text": "Hello world",
  "targetLanguage": "zh-CN"
}
```

成功返回 HTTP 2xx 和 JSON（字段在顶层，不包在 `data` 中）：

```json
{
  "translatedText": "你好，世界",
  "detectedSourceLanguage": "en"
}
```

`translatedText` 必须是非空字符串；`detectedSourceLanguage` 必须是字符串或 `null`（无法识别时）。源语言由后端自动识别。支持哪些语言以接入服务为准。

失败应返回非 2xx HTTP 状态。前端对 401、403、404、413、429 提供专门提示，其余状态显示 HTTP 状态码；不会直接展示后端内部错误正文。无效 JSON、字段不匹配、网络错误、超时和取消均有明确提示。

目前没有用户登录或访问令牌协议。**不要将未经鉴权、限流和额度控制的付费翻译接口公开给所有人使用。** 供应商密钥只能保存在后端 Secrets 中；未来需与后端共同设计认证，不能在公开脚本中嵌入共享密钥。前端的长度和并发限制不能替代后端限制。

## 隐私与权限

- 仅点击翻译时发送选中推文的完整正文及目标语言；正文可能包含链接或用户标识，请自行判断是否适合发送。
- 不发送 X Cookie、登录令牌、整条时间线、推文 URL 或单独的作者资料字段。
- 后端会看到请求来源 IP；HTTP 请求仍包含浏览器/网络层正常元数据。
- `@connect *` 用于支持用户自定义后端域名，不表示脚本会扫描或访问任意网站。使用固定后端后，可将它改为该后端的具体主机名，缩小权限。
- 不下载或执行远程脚本，不使用 `@require`。全部页面逻辑包含在 `.user.js` 中。
- 后端是否存储正文及保留多久，必须由后端运营者明确说明；本脚本不能保证后端不留存。
- 当前仅适合本地安装和受控测试。公开发布前应补充实际后端、费用/账号要求、隐私说明及许可证选择。

## 开发与验证

Node.js 22 或更新版本：

```sh
cd x-timeline-translator
npm ci
npm run check
npm test
```

测试通过 jsdom 模拟 X DOM 与 Tampermonkey API，不调用真实翻译服务。覆盖动态推文、去重、缓存上限、语言切换、过期响应、纯文本渲染、错误提示和设置保存。

真实浏览器验收时应检查两个时间线的滚动与切换、引用推文、表情与换行、刷新后的语言设置、连接授权、超时重试及后端返回格式。前后端联调需要先在 `x-translator-server` 实现 `/api/translate`。
